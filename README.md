# Alpha Kids

A parent coach desk. Type a concern in English or Urdu. Get a short plan and a check-in.

Not a doctor. Not for emergencies. No login. No database. Conversation stays in the page session.

## Stack

Next.js 16 · React 19 · Tailwind 4 · Zod · Zustand

Coach replies are **mock** for now (`lib/server/coach/`). No LLM keys required.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
